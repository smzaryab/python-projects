# Python Projects

A collection of Python projects built while learning and practicing
Python programming, problem-solving, and software development
fundamentals.

## Projects

### 1. Random Guessing Game

A console-based number guessing game built with Python using
Object-Oriented Programming principles.

### 2. Email Simulator

A Python-based email simulation project created to practice
Object-Oriented Programming concepts.

### 3. Snake Water Gun Game

A simple console-based game built with Python using functions,
loops, conditionals, and user input.

## Technologies & Concepts

- Python
- Object-Oriented Programming
- Functions
- Loops
- Conditional Statements
- Exception Handling
- Problem Solving
